# 알바노트

하우머치를 참고해 만든 개인용 알바 급여·근무 달력 웹앱입니다. 광고·결제가 없고, 기록은 기기 브라우저와 본인만 들어갈 수 있는 Cloudflare 동기화 서버에 저장됩니다.

- 주소: https://albanote.pages.dev (Cloudflare Access 로그인 필요, 맥북·폰 동기화)
- 예전 주소 https://glchdnoel.github.io/albanote/ 에서는 동기화가 동작하지 않습니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 틀, 보안 정책(CSP) |
| `app.js` | 계산·화면·저장·동기화 로직 |
| `merge.js` | 맥·폰 기록 합치기(id 단위 3-way 병합) |
| `functions/api/sync.js` | 동기화 서버(Cloudflare Pages Functions + D1). Access 토큰 검증, 허용한 이메일 한 명만 |
| `tests/` | `node tests/test_merge.mjs`, `node tests/test_sync_api.mjs` (Node 22.5 이상) |
| `style.css` | 디자인 |
| `manifest.webmanifest` | 홈 화면 앱 이름·아이콘 |
| `sw.js` | 오프라인에서도 열리게 하는 캐시 |
| `icons/` | 앱 아이콘 |

## GitHub Pages로 올리기 (무료, 처음 한 번)
1. github.com에 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름에 `albanote` 입력 → **Public** 선택 → **Create repository**
   - 무료 계정에서 GitHub Pages는 공개 저장소만 됩니다. 코드만 공개되고, 내 급여 데이터는 폰에만 있어서 올라가지 않아요.
3. 만들어진 화면에서 **uploading an existing file** 클릭 → 이 폴더의 파일과 `icons` 폴더를 전부 끌어다 놓기 → **Commit changes**
4. 저장소의 **Settings → Pages** → Branch를 `main`, 폴더 `/ (root)`로 선택 → **Save**
5. 1~2분 뒤 `https://내아이디.github.io/albanote/` 주소가 생깁니다.

## 아이폰 홈 화면에 추가
1. 아이폰 **Safari**로 위 주소 열기 (크롬 X)
2. 아래 공유 버튼 → **홈 화면에 추가** → 추가
3. 이제 홈 화면 아이콘을 누르면 주소창 없는 앱으로 열립니다.

## 꼭 알아둘 것
- 데이터는 기기에만 저장됩니다. 폰을 바꾸거나 Safari 데이터를 지우면 사라지니 **설정 → 기록 보관하기 → 기록 파일로 저장하기**를 가끔 해주세요. (14일 넘으면 앱이 알려줍니다)
- Safari 탭에서 쓰던 데이터와 홈 화면 앱의 데이터는 따로 저장됩니다. 홈 화면 앱으로만 쓰세요.
- 코드를 고쳐서 다시 올릴 때는 `sw.js` 맨 위 `VERSION`의 숫자를 올려주세요. 그래야 폰이 새 버전을 받습니다.

## 계산 기준
- 주휴수당: 주(월~일) 15시간 이상 + 결근 없음 → (주 근로시간, 최대 40) ÷ 40 × 8 × 시급
- 야간(22~06시)·연장(하루 8시간 초과)·휴일 +50%, 휴일 8시간 초과 +100% (5인 이상 사업장만)
- 3.3%: 소득세 3% + 지방소득세 0.3%
- 4대보험(근로자 부담, 연도별 자동 적용 — `app.js`의 `RATE_TABLE`)
  - 2026년: 국민연금 4.75%, 건강보험 3.595%, 장기요양 건보료×13.14%, 고용보험 0.9%
  - 2027년: 국민연금 5.0%, 건강보험 3.595%, 장기요양 건보료×13.90%, 고용보험 0.9%(발표 전, 2026년 값)
- 미반영: 근로소득세(간이세액표), 보험료 상·하한, 주 40시간 초과 연장, 공휴일 자동 표시

## 동기화 구조
- Cloudflare Access가 사이트 전체를 잠그고, 허용한 이메일로 받은 인증 코드로만 들어갈 수 있음
- `/api/sync`는 Access 토큰(서명·aud·iss·만료·이메일)을 다시 검증. 설정값이 없으면 아무 데이터도 주지 않음
- Pages 환경변수(Production): `ACCESS_TEAM_NAME`, `ACCESS_AUD`, `ALLOWED_EMAIL` / D1 바인딩 이름: `DB`
- 버전 번호(rev)가 맞을 때만 저장 → 두 기기가 동시에 저장해도 덮어쓰지 않고 다시 합침
- 하루 한 번, 그날 첫 변경 직전 상태를 D1 `history` 테이블에 60일 보관 (비상 복구용)
- 오프라인이면 기기에 저장해 두고, 앱으로 돌아오거나 인터넷이 연결되면 자동으로 맞춤

## 보안
- 외부 라이브러리 없음, 요청은 같은 주소(`/api/sync`)로만 (CSP로 같은 주소의 파일만 실행 허용)
- 동기화 요청·로그인 요청은 서비스 워커가 캐시하지 않음
- 입력값과 백업 파일은 형식 검사를 거친 뒤에만 화면에 표시
